Independent community project.

Requires Omarchy’s Lua Hyprland API and KeyboardPanel, Python 3.11+, and libxkbcommon. App focus needs user access to /dev/uinput; dictation uses Voxtype.

01 / Clone

Keep the checkout somewhere permanent.

git clone https://github.com/fraction12/omarchy-codex-micro.git
cd omarchy-codex-micro
02 / Device access

Install the device-specific rule once, then reconnect your Micro. For Bluetooth, pair it through your system settings first.

sudo install -m 0644 udev/70-omarchy-codex-micro.rules /etc/udev/rules.d/70-omarchy-codex-micro.rules
sudo udevadm control --reload-rules

This grants access to the Micro interface, not general keyboard or uinput access.

03 / Install & open

Run as your normal desktop user, without sudo.

scripts/install
omarchy-shell shell toggle fraction12.codex-micro '{}'

Before changing an action: inspect the starter mappings. Your first action edit replaces the device’s configured layers 2 and 3. Installation itself does not write to the device.

Layer 1 stays Codex-owned, except for the optional Quick Micro dial-double toggle. Avoid editing through Input at the same time.
